## 1. 何が面白いゲームか

**タクティカルな TPS。ちゃんとメタルギアらしい TPS であること。**

### 何を強みにしないか

**「ヘッドショット重視の、純粋なエイム勝負」を軸にしない。**

そこを軸にすると、Apex なり他のシューターをやればいい話になる。あえてこれを作る
理由が消える。腕前の差が出る場所を「照準を合わせる速さ」に置かない。

### 誤読しやすい所: エイムを弱くするという意味ではない

**頭に当たれば 1 発で死ぬ。これは残す。**

「軸にしない」を「エイムを弱くする」と読むと逆効果になる。**エイムが脅威として
強いままだからこそ、それを迂回する手に価値がある。** 正面から撃ち合えば危ない、
という前提があって初めて「回り込む」「情報を取ってから動く」「そもそも見つからずに
通る」が意味を持つ。

脅威を消したら、迂回するものが無くなる。エイムで勝負する人が居ることが、
タクティカルであることの**前提**になっている。

軸にしない、というのは:

- **エイムだけが上手ければ勝てる、にはしない** (情報と位置でひっくり返せる)
- **得点がキルだけに付く、にはしない** (索敵にも価値を置く)

であって、「当てても死なない」ではない。

### この判断が既に効いている所

いまの実装はエイム勝負を前提にした数字が入っている。1 が決まったので、見直す対象:

| いまの値 | エイム勝負の前提 | 状態 |
|---|---|---|
| 拳銃 / 突撃銃が遠距離でも頭 2 発 | 頭を撃てば勝ち | **直した** ([weapons.md](weapons.md)) |
| 得点はキルと残機だけ | 撃ち合いに勝つこと以外に価値が無い | 未 |

個別の武器の調整と、その理由は [weapons.md](weapons.md) にある。

## 2. 勝敗 (match type)

いまウチにあるのは 1 つだけ。チケット制のチーム戦 (MGO2 でいう TDM に近い)。

### MGO2 のルール一覧 (事実。採否は未定)

| 略称 | 内容 |
|---|---|
| **DM** | 全員が敵の個人戦。倒すと得点、死ぬとチケットが減る。暫定 1 位は**体が発光**して位置が割れる |
| **SDM** | 全員ステルスの DM。時間とともに行動範囲が狭くなる。近くに敵がいるとアラームが鳴る。**復活無し** |
| **SCAP** | 1 つのケロタンを全員で奪い合う。持つとカウントが減り、最初に 0 にした者が勝ち。**倒した相手のカウントが減る**ので、無闇に倒すと不利になる |
| **TDM** | 2 チーム。倒すと相手のチケットが減る。先に 0 にしたほうが勝ち |
| **CAP** | 2 チームでケロタンとガーコを奪い合う。自陣に留めるとカウントが減る。両方置くとリセット (延長ルールでは停止のみ)。2 つ置くと減りが速い |
| **BASE** | 点在する拠点を制圧。全制圧か、時間切れ時の制圧数で勝敗。**同時に踏む人数で制圧時間が変わる** |
| **BOMB** | 設置チームと解除チーム。設置側は拠点 1 つを爆破すれば勝ち。解除側は冷却スプレーで凍結、**同時に噴射する人数で解除時間が変わる**。爆弾の残数 (3) を 0 にすれば解除側の勝ち |
| **RACE** | 赤はガーコ、青はケロタンをチェックポイントへ規定回数通す。**通過ごとにチェックポイントが移動する** |
| **RES** | 攻撃 / 防御。攻撃側は防御陣地のガーコを持ち帰るか全滅させる。防御側は守り切るか全滅させる。**復活無し** (設定で幽霊になれる) |
| **TSNE** | 潜入 / 防御。潜入側はステルス迷彩、ガーコかケロタンをゴールへ運ぶ。**潜入側はナイフ以外の殺傷武器を持てず、防御側は非殺傷武器を持てない** (奪うのは可)。復活無し |
| **SNE** | 赤・青・スネークの三つ巴。スネークは気絶かホールドアップでドッグタグを 3 枚集めれば勝ち。赤青はスネークを規定回数倒す |
| **INT** | 休憩。戦績に反映されない |

### 読み取れる作りの型 (事実の整理。決定ではない)

- **復活の有無**が難易度と緊張を決めている (DM/TDM は復活あり、SDM/RES/TSNE は無し)
- **人数で時間が変わる**仕掛けが複数ある (BASE の制圧、BOMB の解除)。集まる理由になる
- **倒すことが不利になる**ルールがある (SCAP)。撃ち合い以外の判断を強制する
- **持てる物をルールが縛る**ことがある (TSNE の殺傷/非殺傷)
- **位置が割れる仕掛け**がある (DM の 1 位が光る、SDM のアラーム)

### 決まったこと: 部屋にルールを固定で割り当てる

部屋は最初から 5 つ置いてある (alpha〜echo、定員 8 = 4 対 4)。**部屋ごとにルールを
固定する**。部屋を立てるときに選ぶ形にはしない。

| 部屋 | ルール | 状態 |
|---|---|---|
| alpha | **DM** 個人戦 | 作る |
| bravo | **TDM** チーム戦 | 作る (いまの実装がこれに近い) |
| charlie | **TDM** | 同上 |
| delta | **TSNE** 潜入 / 防御 | **入れない (inactive)**。非殺傷武器が要るため |
| echo | **INT** 休憩。戦績に残らない | 作る |

TSNE を止めているのは、**潜入側がナイフ以外の殺傷武器を持てない**という縛りが
ルールの核で、非殺傷武器 (麻酔銃・スタングレネード) が無いと成立しないため。
枠は残しておく — 何を作れば開くかが分かる形にしておきたい。

### まだ決めていないこと

- [ ] 復活の有無をどう扱うか (いまは常に復活あり)
- [ ] DM の「暫定 1 位が光る」を入れるか
- [ ] INT で何ができるか (自由に動ける? 撃てる?)

## 3. 情報 — 誰が何をいつ知るか

**ここが背骨。** タクティカルであることの中身がここに入る。

### 決まったこと: 敵対とリンクは別のグラフ

いままで「味方」を 1 つの概念にしていた。**撃たない相手**であり、**位置が見える
相手**でもあった。これを 2 つに割る。

| | 何を決めるか | どう決まるか |
|---|---|---|
| **敵対** | 誰を撃てるか / 爆風が入るか / 点が入るか | ルールが決める (DM は全員、TDM は陣営) |
| **リンク** | **誰に情報が流れるか** | **プレイヤーが敬礼して作る** |

陣営が静的なのに対し、**リンクは動的**。試合中に増え、切れ、選ばれる。

判定は `isHostile(a, b)` と `isLinked(a, b)` の 2 つに分ける。ルールごとに
前者を差し替える。

### 決まったこと: リンクは敬礼で作り、CQC で抜かれる

- 味方でも**自動では見えない**。敬礼してリンクして初めて情報が流れる
- リンクは**網**。A-B と B-C が繋がっていれば A も C を知る
- リンク中の相手を **CQC で捕まえて scanning** すると、**その網の全員**が漏れる
- 抜いた情報は**抜いた側の網にも流れる**。自分が味方と繋がっていれば、その全員に
  相手の網が見える
- だから **敢えてリンクしない**という戦略が成立する

#### 同じつまみでリスクとリターンが両方上がる

```
網を大きくする → 味方の索敵結果が自分にも来る   (得)
              → 誰か 1 人捕まると全員漏れる     (損)
```

繋ぐ人数がそのまま戦略になる。1 人とだけ繋ぐ慎重な打ち方と、全員と繋いで一気に
見る打ち方が両立する。**どちらが正しいかは状況で変わる**ので、毎回選ぶことになる。

### 決まったこと: 漏洩は「発光」として体に出る

抜かれた側の**体が光る**。レーダーに点が出るのではなく、**体そのもの**が光って
位置を知らせる。

- **抜かれた本人が、抜かれたと分かる** (自分が光っているので)
- 味方からも、誰が漏れているかが見える
- **死ねば止まる。** 死が漏洩を止める手段になっている
- 持続はおそらく 1 分程度 (要確認)

DM の「暫定 1 位が光る」も同じ語彙。**光る = 位置が公になっている状態**として
統一されている。

#### この形にすると実装が軽い

持つのは「誰が何を知っているか」ではなく、**当人が光っているかどうか**。

```
× 「A は B の位置を 60 秒間知っている」   見る側 × 見られる側の表
○ 「B は 60 秒間光っている」              見られる側だけの札
```

配信の規則に 1 行足すだけで済む。「光っている相手は視線を問わず送る」。
壁抜けの発光は味方表示用に既に実装がある (remotePlayer.ts の ALLY_GLOW_*)。

### なぜこれで「タクティカル」なのか

- 情報を得るには、相手 (味方) に**近づいて敬礼する**という行動が要る
- 情報を持つことが**弱点になる**。捕まると自分だけでなく網の全員が漏れる
- 繋ぐか繋がないか、何人と繋ぐかを状況ごとに選ぶ
- 漏れたことが**見える**ので、漏れた側にも打つ手がある (隠れる / 死ぬ)

MGO2 の得点表で **SCANNING がキルの 2 倍 (10 点)** だったのはこれ。索敵は
「見つけること」ではなく**敵の情報網を抜く行為**だった。

### 既にある判断 (残す)

- 見えていない相手の位置は**送らない**。見えなくなったことすら知らせない
  (「見えなくなったと伝えること自体が情報」)
- 見えるかどうかの起点は**目ではなくカメラ**。三人称なので、画面に映るかどうかを
  決めているのはカメラの位置

### 決まったこと: 抜けるのはスキルを持つ者だけ

scanning するには **SCANNING スキル**が要る。スキルが無いと **Plug を持てない**
(切り替え HUD に `S. PLUG-S` として並んでいる道具)。誰でも抜けるわけではない。

**スキルが「できること」を塞いでいる。** 数値の修正 (+10% ダメージ) ではなく、
動詞そのものの可否を決めている。だから装備選択が「強い組み合わせ探し」ではなく
**役割の選択**になる。索敵役を誰かがやらないと、網は抜けない。

そしてこれがリンクの設計と噛み合っている:

```
網を大きくする      得も損も大きくなる
抜ける人は限られる  スキルを 1 枠使った人だけ
```

**全員が抜けるなら誰も繋がない。** 抜ける人が限られているから、網が大きいことの
危険が現実味のある賭けになる。

### 決めること

- [ ] リンクで流れるのは**位置だけ**か、**その人が見ているもの**もか
- [ ] リンクはいつ切れるか (死亡 / 距離 / 時間 / 手動)
- [ ] 発光の持続 (1 分は記憶に基づく暫定値)
- [ ] DM にリンクはあるか (全員が敵なので、あるとすれば裏切り前提の同盟になる)
- [ ] 敬礼は相互に必要か、片方が敬礼すれば繋がるか
- [ ] 抜くには CQC で捕まえる必要がある = **捕まえる動詞**が要る (4 で決める)

## 5. 持ち物 (entity)

### 決まったこと: 手にあるのは常に 1 つ。持ち替えて使う

枠を並べて同時に使うのではなく、**1 つの手を持ち替える**。

### 決まったこと: 系統は 2 つ、武器系は 4 枠

| 系統 | 中身 | 操作 |
|---|---|---|
| **武器系** | 主武器 / 副武器 / 投擲 / **ナイフ** | 押す = トグル、長押し = 一覧 |
| **道具系** | 箱・双眼鏡・カメラ・プラグ … | 同上 (別のキー) |

**ナイフも枠。** 最初から 4 つ持っている状態になる。

これが効くのは、**ナイフを持っている間は銃が撃てない**ということ。いまは銃を
構えたまま一瞬で刺せるので、刺しに行くのに何も失っていない。枠にすると、
刺しに行くと決めた時点で撃つ手段を手放す。

CQC で捕まえる (3 の scanning に要る) も同じ枠に乗る。掴みに行くのは、
銃を置いて近づくということになる。

そして**刺されば即死**になる (背後も正面も)。代償が先に払われているため。
数字と順番の注意は [weapons.md](weapons.md) を参照 — **持ち替えより先に即死に
してはいけない**。

### 決まったこと: 手榴弾も持ち替える。理由は速さ

### 決まったこと: 手榴弾も持ち替える。理由は速さ

銃を構えたまま投げるのではなく、**手榴弾に持ち替える**。

理由はリアリティではない。**軽い物を持つと速く動けるから**。手榴弾は副武器より
さらに軽いので、**手榴弾を持って走る**という手が成立する。移動そのものが装備の
選択になる。

いまの実装は既に「持っている物の重さ」で速度を決めている
(`carrySpeedScale(weaponOf(this.weaponKind))`)。足りないのは**手榴弾が「持って
いる物」になれない**こと。持ち替えを入れれば、重さの仕組みがそのまま生きる。

```
突撃銃 3.5kg   基準
拳銃   0.95kg  +15%
手榴弾 (未定)  さらに速い
```

持ち替えは損得の両方を持つ:

- **損** 投げると決めた瞬間に銃を手放す。外したら丸腰の時間ができる
- **得** 軽い物を持っている間は速い

### 決まったこと: 中身の割り振り

| 系統 | 枠 | 入る物 |
|---|---|---|
| 武器系 | 主武器 | 突撃銃 / 狙撃銃 |
| | 副武器 | 拳銃 |
| | **support** | 手榴弾 / クレイモア / **弾倉 (囮)** |
| | ナイフ | ナイフ |
| 道具系 | | ダンボール (いまはこれだけ) |

**support は 1 枠だが、中身は 1 つとは限らない。** 湧くときに選ぶのは手榴弾か
クレイモアのどちらか。弾倉は選ぶ物ではなく**撃った弾が溜まって増える**ので、
持っていれば一覧に並ぶ。だから武器系の一覧は 4 つとは限らず、5 つになることがある。

**`NONE` (手ぶら) は入れない。** 一番速い状態を作る話は、いまは要らない。

**持ち替えの時間は一律。** 重さでは変えない。重い銃をしまうのが遅い、はやらない
— 重さは既に移動の速さで効いているので、二重に効かせると狙撃銃が使えなくなる。

### いま散らばっている状態 (実装)

「手に何があるか」が 4 か所に分かれている。1 つに寄せることになる。

| どこ | 何を表しているか |
|---|---|
| `WeaponId` + `slot` | 構えている銃 |
| snapshot の flags | `boxed` / `holdingGrenade` / `concentrating` / `salute` |
| `Locomotion` | `stab` / `claymore_windup` / `claymore_place` / `sneak` (箱) |
| `SupportId` | 投擲の枠に何を入れたか |

MGO2 から読み取れた事実 (スクリーンショットから。推測ではない):

- 持ち物は **1 枠**。銃も手榴弾も道具も、同じ枠を持ち替える。手榴弾を持っている
  間は銃が背中に納まっている
- 押すだけで 2 つをトグル、長押しで一覧から入れ替え
- 十字左が道具、右が武器
- 一覧は**1 本のリストを L 字に折って**表示する。現在の選択が角に来て、前半が上へ、
  後半が右へ伸びる。**画面の中央を塞がないため**
- `NONE` (何も持たない) が明示的な選択肢として並ぶ
- HUD: 装填弾は**目盛り**、予備弾は**数字**。数字を読まなくても減りが分かる
- スキルは 3 枠・レベル制 (ASSAULT RIFLE+ 2、RUNNER 1、THROWING MASTERY 3 など)

## 付録: MGO2 の得点表 (事実)

ラウンド結果の画面から読み取った実測値。

```
KILL COUNT      2 × 5  = 10
SCANNING        0 × 10 = 0      ← キルの 2 倍
GOAL            0 × 10 = 0
STUN COUNT      2 × 5  = 10     ← キルと同点
TEAM WIN        1 × 5  = 5
WAKE COUNT      0 × 5  = 0      ← 倒れた味方を起こす
TARGET 1ST GET  0 × 5  = 0
OTHER           6 × 1  = 6
ROUND SCORE            31
```

**索敵がキルの 2 倍、気絶がキルと同点。** 撃ち合いに勝つことが最高の価値ではない、
という配点になっている。1 で決めた「エイム勝負を軸にしない」と同じ方向。
