# このゲームのドメイン

MGO2 という遊びそのものを、three も通信も知らない言葉で書いた層。

**ここが数字の出どころ。** 下の表を変えてから、コードを合わせる。表と実装が
ずれたら [spec.test.ts](spec.test.ts) が落ちる。

なぜその数字なのかは [docs/design.md](../../docs/design.md) と
[docs/weapons.md](../../docs/weapons.md)。

## 体

体力は **100** とする。撃たれずに屈んで待てば 35 まで回復する。

**銃弾は至近距離で頭に当たれば 1 発で死ぬ。** エイムが脅威として強いままだからこそ、それを
迂回する手に価値が出る。

部位ごとの基準ダメージは以下とする。距離で減衰する。

## 銃

1 回の装弾数と予備弾は以下とする。

<!-- 検査:銃 -->
| 武器 | 名前 | 装弾数 | 予備 | 重さ(kg) | リロード(秒) |
|---|---|---:|---:|---:|---:|
| smg | P90 | 50 | 100 | 2.6 | 3.0 |
| rifle | AK47 | 30 | 90 | 3.5 | 2.5 |
| sniper | XM2010 | 5 | 15 | 5.5 | 3.2 |
| shotgun | M870 | 6 | 24 | 3.6 | 4.4 |
| m9 | M9 | 12 | 48 | 0.95 | 2.1 |
| m1911 | M1911 | 7 | 35 | 1.05 | 2.3 |
<!-- /検査 -->

**重さは移動の速さに効く。** 3.5kg を等倍として、1kg 軽いごとに 6% 速い。

    速さ = 1 + (3.5 − 重さ) × 0.06

    P90 105%   AK47 100%   XM2010 88%   M9 115%   手榴弾 119%

軽い物に持ち替えて走る、を戦法として成立させるためにこの形にしてある。

### 棲み分け

**同じ距離で 2 挺が競合しないようにする。** 主武器の 3 挺は「頭 1 発で殺せる
間合い」の広さと、その代わりに何を差し出すかで分かれる。

| | 受け持つ距離 | 強み | 代償 |
|---|---|---|---|
| **SMG** (P90) | 〜12m | 装弾 50 発、900 発/分、反動が小さい。軽くて小回りが利く | **頭 1 発の間合いが狭い** (30m から先は頭 4 発)。リロードが 3 秒と長い |
| **AR** (AK47) | 15〜40m | 頭 1 発が 25m まで届いて連射もできる万能 | 遠距離は頭 1 発にならず、狙いにくい |
| **SNIPER** (XM2010) | 全距離 | **どこから撃っても頭 1 発。**スコープがある | 連射できない (1.57 秒に 1 発)、重い (速さ 88%)、弾倉 5 発 |
| **SG** (M870) | 〜8m | **8m 以内は 50 削って吹き飛ばす。**部位を問わない。曲がり角を取る | 16m で 25、24m で 12.5、それより先は当たらない。ポンプ式で 1.7 秒に 1 発 |

頭 1 発で殺せる距離と、そこから先の落ち方:

<!-- 検査:射程 -->
| 武器 | 等倍まで(m) | 頭打ち(m) | 下限 |
|---|---:|---:|---:|
| smg | 12 | 30 | 0.25 |
| rifle | 25 | 60 | 0.3 |
| sniper | 200 | 200 | 1 |
| shotgun | 200 | 200 | 1 |
| m9 | 200 | 200 | 1 |
| m1911 | 12 | 24 | 0.3 |
<!-- /検査 -->

    距離        SMG        AR
    12m まで    頭 1 発    頭 1 発
    20m         頭 2 発    頭 1 発      ← ここが AR の間合い
    30m 以降    頭 4 発    頭 1〜2 発
    60m 以降    頭 4 発    頭 4 発      どちらも狙撃銃に負ける

### 弾道

**弾はまっすぐ飛ばない。** 距離に応じて落ちるので、遠くを狙うほど狙点より上を
撃つ必要がある。

初速と、弾に掛かる重力は以下とする。**実銃の値を採る。**

<!-- 検査:弾道 -->
| 武器 | 初速(m/s) | 重力(m/s²) |
|---|---:|---:|
| smg | 715 | 9.8 |
| rifle | 715 | 9.8 |
| sniper | 880 | 9.8 |
| shotgun | 380 | 9.8 |
| m9 | 120 | 9.8 |
| m1911 | 390 | 9.8 |
<!-- /検査 -->

落差は**速さの 2 乗で効く**ので、拳銃だけが目に見えて落ちる。

    落差      25m      50m      80m
    XM2010    0.4cm    1.6cm    4.0cm
    P90       0.6cm    2.4cm    6.1cm
    AK47      0.6cm    2.4cm    6.1cm
    M9        2.1cm    8.5cm    21.7cm

一時期 AK47 だけ 420 m/s に落としてあった。**落ちていることが読み取れる**ように
するためで、80m で 18cm 落ちる代わりに実銃の値を捨てていた。やめた理由は 2 つ:

- **基準が武器ごとにばらついた。** P90 と M9 は実銃のまま、AK だけ遊びのための
  数字。並べると「近距離の SMG がいちばん素直に飛んで、中距離の AR がいちばん
  落ちる」という、役割と逆向きの並びになっていた
- **距離を読ませる仕掛けは他にある。** 頭 1 発の間合い (上の表) と距離減衰が
  既にその役をしている。同じことを弾道でも二重にやる必要が無い

放物線を引くのは sim (judge/bullet.ts)。ここが持つのは速さと重力だけ。

連射は SMG が 900 発/分 (0.065 秒間隔)、AR が 660 発/分 (0.09 秒)。
**胴で削り合えばほぼ互角**にしてある — SMG は 1 発 15 で 7 発 (0.39 秒)、
AR は 20 で 5 発 (0.36 秒)。**近くでは AR がわずかに速い。** SMG が勝つのは
弾倉の大きさと足の速さであって、殴り合いの強さではない。

> **SG (ショットガン) はまだ無い。** 短距離で、当たった相手を怯ませるので突撃に
> 向く。**頭 1 発では死なない**枠として入れる (design.md の 5)。

## 投げる物・置く物

1 つの命で持てる数は以下とする。倒れて湧くたびに戻る。

<!-- 検査:支援 -->
| id | 名前 | 数 |
|---|---|---:|
| grenade | GRENADE | 3 |
| claymore | CLAYMORE | 2 |
| decoy | DECOY | 2 |
<!-- /検査 -->

三者で**効く相手が割れる**。手榴弾は相手を動かす (止まっている相手に効く)、
クレイモアは置いて待つ (動いている相手)、囮は撃たせる (**見ている相手**)。
どれが強いかではなく、相手が何をしてくるかの読みになる。

弾倉 (`magazine`) は枠で選ばない。撃った弾が 1 弾倉ぶん溜まるごとに増える。

手榴弾は爆心 **75** / 届く **7m**。**どちらも単体では死なない** (体力 100)。

クレイモアは **反応と爆風で別**。

    反応  正面 4m の扇。背後や真横を通っても起爆しない
    爆風  全方位 6m。至近 75 / 端 25。近ければ転ぶ

**向きが意味を持つのは「いつ起爆するか」まで。** 爆ぜてしまえば火薬は全方位に
効く — 真後ろに立っていた人だけ無傷、は物として嘘になる。置く側から見ても、
背後を通られたら起爆しないという時点で向きの代償は払っている。

## 音

**姿が見えない相手を知る唯一の手段。** どこまで届くかを変えると「足を止めて
聞く」「屈んで近づく」という判断がそのまま変わる。

足音は走りで **20m**。姿勢の倍率 (rule/footsteps.ts) を掛けたものが実際に届く
距離で、しゃがみ 0.45 倍で 9m、ダンボール 0.25 倍で 5m。**屈めば近づける。**

銃声は武器ごとに違う。

<!-- 検査:銃声 -->
| 武器 | 届く距離(m) |
|---|---:|
| smg | 110 |
| rifle | 130 |
| sniper | 170 |
| shotgun | 140 |
| m9 | 20 |
| m1911 | 95 |
<!-- /検査 -->

**撃てば居場所が漏れる。** 狙撃銃が一番広いのは「遠くから安全に撃てる代わりに、
音は遠くまで行く」という交換で、拳銃が一番狭いのは近づいて撃つ道具だから。

**姿が見えている相手の音は鳴らさない。** 見えているなら位置は既に届いていて、
音まで出すと同じことを二重に伝えることになる。

距離と方角を測るのも、遮られているかを見るのも sim。ここが決めるのは
「その距離なら聞こえるか」だけ (rule/noise.ts)。

## 近接

間合いは **2m**。**どこを刺しても 100** — 背後も正面も即死。

倒れている相手は、**ナイフを構えて見下ろせば**刺さる (`-0.35 rad` 以下)。
真っ直ぐ前を刺しても届かない。

**代償が先に払われている。** ナイフは持ち替えの枠なので、刺しに行く人は
**銃をしまってから近づいている** — 撃つ手段を手放し、間合いに入るまで無防備で
いる。そこまでやって届いたなら絶対、という釣り合い。

(持ち替えが入るまでは正面 50 にしてあった。銃を持ったまま一瞬で刺せる状態で
即死にすると、代償が無いまま報酬だけが残るため。)

## 試合

<!-- 検査:試合 -->
| | 値 |
|---|---:|
| 残機 (ticket) | 20 |
| 試合の長さ (秒) | 300 |
| 始めるのに要る人数 | 2 |
| 席を空けて待つ (秒) | 30 |
<!-- /検査 -->

**残機は死因を問わず 1 減る。** 撃たれても自爆しても自陣の損は同じで、倒した
側には何も入らない。「殺されるくらいなら自死する」を成り立たなくするため。

0 にされた側が負け。時間切れなら多く残っているほうが勝ち。残機はサーバーの
環境変数で上書きできる (`MGO2_TICKETS`) — **実際に回して詰める**数なので、
箱の上で試すのに再配置が要らないようにしてある。

## 時間

<!-- 検査:時間 -->
| | 秒 |
|---|---:|
| 湧いた直後の無敵 | 3 |
| 倒れてから湧けるまで | 5 |
| 支度の打ち切り | 30 |
| OK が効くまで | 3 |
| 持ち替え | 0.3 |
<!-- /検査 -->

**早く選んだぶん早く戻れる、にはしない** (OK が効くまで 3 秒)。選ぶのが速い
ことは腕前ではない。

### 単位は秒。ミリ秒だけ名前に書く

時間の定数は**秒**で置く (`RESPAWN_DELAY = 3` / `DOWN_DURATION = 5` /
`CHOOSE_TIMEOUT = 30`)。時計と突き合わせる都合でミリ秒を持つものは
**名前の末尾に `_MS`** を付ける — いまは `RECONNECT_GRACE_MS` と
`LAG_WINDOW_MS` の 2 つだけ。

名前で分けるのは、**注釈だけだと写し間違える**から。`READY_SECONDS` の
説明に隣の `RECONNECT_GRACE` の「(ms)」が写っていて、秒の定数がミリ秒だと
書いてあった。値も名前も正しく、注釈だけが嘘という一番気づきにくい形になる。

## 状態 (Life)

席に着いてからの状態。**遷移できる組は表で決まっている**
([lifecycle.ts](lifecycle.ts))。

| | |
|---|---|
| `joining` | 席はあるが、まだ位置を知らせていない。誰にも配らない |
| `choosing` | 装備を組んでいる。戦場に居ない |
| `spawning` | 湧いた直後。戦場に居るが、まだ撃たれない。撃てば自分から解く |
| `alive` | 戦場に居て、撃たれる |
| `downed` | 倒れている。自分で起きる |
| `dropped` | 切れた。席は 30 秒だけ空けて待つ |

## 情報 (決めてあるが、まだコードに無い)

**ここが遊びの背骨。** 敵対とリンクは別のグラフとする。

| | 何を決めるか | どう決まるか |
|---|---|---|
| 敵対 | 誰を撃てるか | ルール (DM は全員、TDM は陣営) |
| リンク | **誰に情報が流れるか** | **プレイヤーが敬礼して作る** |

- 味方でも自動では見えない。**敬礼してリンクして初めて**情報が流れる
- リンクは**網**。A-B と B-C が繋がっていれば A も C を知る
- リンク中の相手を CQC で捕まえて scanning すると、**その網の全員**が漏れる
- 漏れた側は**体が光る**。死ねば止まる
- scanning には skill が要る (無ければ Plug を持てない)。誰でもできはしない

**発光だけは先に入った。** 個人戦 (DM) の 1 位が光って位置が漏れる — 遮蔽を
無視して配る + 体を光らせる、という同じ道を通してある。リンクを抜かれた相手も
ここに乗る予定。

## 申告・意思・状態

クライアントから届くものを 3 つに分ける。**扱いが違う。**

    申告 (claim)   当てた・落ちた            → 検算してから通す
    意思 (intent)  選ぶ・湧く・置く・拾う    → ドメインルールで受け付けるか決める
    状態 (state)   位置・姿勢・向き          → そのまま預かる

**手にある物は「状態」ではなく「意思」。** 位置と一緒に流れてくるので長らく
素通りで書き込んでいたが、それだと**選んでいない狙撃銃を名乗って撃つ**が通る
(頭 1 発が 100 から 130 になる)。持てるかどうかはドメインルールが決める
([player/equip.ts](player/equip.ts) の `canHold`)。

判断の材料は**持ち物 (kit) 1 つだけ**にしてある。選んだ物にも拾った物にも特例を
作らない — 主武器だけ特例で通していた頃は、**地面に置いても名乗り続けられた**
(置いた銃を他人に拾わせながら、自分もその銃として撃てる)。

弾いたときは**前の値のまま**にする。送り返して直させるより、こちらが知っている
姿を配り続けるほうが素直で、他人の画面には正しい物が映る。

**まだ通していないもの:** 持ち替えにかかる時間 (`SWITCH_TIME`) はクライアント
だけが数えている。サーバーは「その瞬間に持てるか」しか見ていないので、
持ち替えを待たずに撃つのは今のところ止まらない。

## 語彙

コードに出てくる名前と意味。**ここに無い言い方をコードで使わない。**

| 名前 | 意味 |
|---|---|
| **Player** | 人。名前・陣営・体力・状態。**他人から見えるのはここまで**で、名簿が配るのもこれ |
| **MatchPlayer** | 試合の中の人。`Player` + 位置・持ち物・成績。**サーバーだけが持つ** (的も含む) |
| **Soldier** | **体。**画面が動かす三次元の姿 (`presentation/scene/actor`)。自分が `Soldier`、他人が `RemoteSoldier` |
| **Session** | 接続。`server/index.ts` に居る。socket・届く間隔・誰に何を配ったか |
| **Pose** | ある時刻の姿。**当てたという申告を遡って照合する**のに使う |
| **Match** | 試合 = 部屋 1 つ。ルール (Mode) を持つ |
| **Mode** | 部屋のルール (`DM` `TDM` `TSNE` `INT` `PRACTICE`)。誰が敵かはこれが決める |
| **的 (bot)** | 接続を持たない MatchPlayer。練習部屋に並ぶ棒立ち |
| **席 (seat)** | 部屋の中の 1 人分の枠。切れても 30 秒は空けて待つ |
| **残機 (ticket)** | 陣営の持ち点 |
| **Life** | 上の 6 状態 |
| **Locomotion** | 体の動き (`idle` `sneak` `crouch_idle` `stab` `roll` `away` …) |
| **WeaponId** | 撃てる物 (`smg` `rifle` `sniper` `shotgun` `m9` `m1911`)。**主武器も副武器も同じ表**から引く |
| **Slot** | どの枠に入るか (`primary` `secondary` `support` `knife` `tool`)。**宣言は `HELD` の 1 か所**で、選べる一覧 (`CHOICES`) はそこから導く |
| **HeldId** | いま手にある物。1 つだけ。`WeaponId` + 投げる物 + ナイフ・箱 |
| **持ち物 (kit)** | その命で手にできる物の全部。選んだ装備 + 拾った物。**置けば外れる** |
| **Family** | 持ち物の系統 (`weapon` / `tool`) |
| **Intent** | **その人が何をしようとしているか。** 押されている動詞だけで、受け付けた結果は入らない |
| **発光** | 位置が公になっている状態。リンクした味方 / 抜かれた相手 / DM の 1 位 |

### 人 (Player) と接続 (Session) は別

同じ人が繋ぎ直せば **Session は新しくなるが、Player は席に残る**。
席を 30 秒空けて待つドメインルールがここに出ている。

```
Player       (ここ)     名前 陣営 体力 状態
                        **他人から見えるのはここまで**
MatchPlayer  (ここ)     Player + 位置 持ち物 成績
                        過去の姿 (照合に使う)
Session      (server)   socket 届く間隔 時計のずれ
                        誰に何を配ったか
```

**人は 2 段。** サーバーだけが `MatchPlayer` を作る (newMatchPlayer / newBot)。
画面が持てるのは名簿で届く `Player` だけで、**問いは両方から同じ形で呼べる**
(`isProtected(player)` はどちらでも通る)。分けていなかった頃、画面側は人を
持てず `Life` を直に握って状態名で比べていた。

**過去の姿は人が持つ。** 接続の側に置きたくなるが、練習部屋の的は接続を
持たないのに撃たれる。撃たれる物はすべて照合の相手になるので、人の側に付く。

## 依存の向き

```
    ui ─▶ game ─▶ sim ─┐
                       ├─▶ domain
    server ─▶ net ─────┘
```

**domain からは誰も見ない。** 見た瞬間に、ドメインルールが幾何や回線の都合を知ることに
なる。陣営 (`Team`) の定義を `net` からここへ移したのもこれ。
[layout.test.ts](layout.test.ts) が留めている。

## 何がここに来るか

**触る理由が「遊びを変えたいから」なら、ここ。** 「そう見えない」「破綻するから
直す」なら sim か game。

    その数字を変えたら、プレイヤーの判断が変わるか
    壊れたとき「バグ」と呼ぶか、「ルール変更」と呼ぶか

装弾数・部位ダメージ・残機・湧きまでの時間は、変えれば遊び方が変わる。
階段を段と読む落差や、補間の速さは変わらない。**数字はここ、幾何は sim** —
「クレイモアが見張るのは前方 60 度」はここ、その角度で内積を取るのは sim。

詳しくは [docs/design.md](../../docs/design.md) の 7。

## 棚

**入れ物の名前は entity。** 「model と logic」のように、何であるかではなく
どう扱うかで分けると、置き場所を決めるたびに迷う。人の話は player/ にある、で
済ませたい。

### 扉が 1 つの棚

`index.ts` を置いた棚は、**そこが唯一の入口**。中のファイルを外の層から
名指ししない。要る物は index が取り次ぐ。

    import { surfaceOf } from '.../domain/stage'          ○
    import { surfaceOf } from '.../domain/stage/surface'  ×

中を名指しできるかぎり、**並べ替えるだけで外が全部書き換え**になる。ステージが
そうなっていた — ステージそのものが `match/stage.ts`、面の宣言が `stage/` に
分かれていて、名前が同じなのに指す物が違い、外の 18 か所がその並びを直に
握っていた。いまは 1 つの棚に寄せて、扉を index にしてある。

同じ形が `infra/link` と `infra/input` にもある。守れているかは
[../layers.test.ts](../layers.test.ts) が見張る。

**幾何は連れてこない。** sim が返すのは**事実**で、それを量に直すのがここ。

    sim     どこに落ちて、誰が何 m 先に、体のどれだけが晒されていたか
    domain  その距離と遮蔽なら何ダメージか、転ぶか、削られて倒れるか
    server  それを実際に引いて、記録して、配る

体の何点が爆心から見えているかを数えるのも、扇の中に居るかを内積で見るのも sim。
**数字と式がこちらに来る。**

逆に、ここから出ていったものもある。どのモーションを流すかを決めるドメインルール
(`resolveLocomotion` と階段まわりの調律値) は presentation/scene/actor/motion.ts へ移した —
触る理由が「動きが変に見える」であって、遊びは変わらないため。

## まだ言葉になっていないもの

設計では決まっているのに、entity が無いもの。

- **Link** — 敬礼で作る網
- **Scanning / Plug** — 網を抜く動詞と、それを持てるスキル
- **発光 (leak)** — 抜かれた側に付くフラグ。持続と、死んだら止まること
- **Skill** — 4 コストの予算。動詞を塞ぐ
- **Round / Time** — 湧き・ラウンド・試合の時間 (design.md の 6 は未着手)
