# このゲームのドメイン

**この層に書いてよいのは「ゲームの説明書に書けること」だけ。**

拳銃が 12 発なのは説明書に書いてある (ここ)。弾が地形に当たって跳ねるのは
書いていない ([../sim](../sim))。迷ったらこの問いに戻る。

なぜ守るかというと、**設計 ([../../docs/design.md](../../docs/design.md)) が
使っている言葉と、コードが使っている言葉を同じにしたい**から。ずれていると、
「手榴弾に持ち替えると速い」と決めた話が、コードでは 4 か所のフラグの組み合わせ
として散らばる。実際にそうなっていた。

---

## 何を扱う層か

| | |
|---|---|
| **扱う** | 人・試合・持ち物・状態・規則。**MGO2 という遊びそのもの** |
| 扱わない | 幾何と物理 (`../sim`)、通信の形 (`../net`)、描画と入力 (`../game`)、画面 (`../ui`) |

three にも DOM にも触らない。**サーバー (bun) がこのディレクトリをそのまま
読み込んで動かしている**ので、触った瞬間に落ちる。

## 地図

```
        Match                     試合 = 部屋 1 つ
          │ players
          ▼
        Player  ───── Team        人
          │              (blue / red)
          ├── Life                いまどの状態に居るか
          ├── Locomotion          体がどの動きの中に居るか
          ├── Footsteps           歩いた距離。足音の間隔
          └── 持ち物
               ├── HeldId         いま手にある物 (1 つだけ)
               ├── Ammo           銃ごとの装填と予備
               └── SupportId      支援の枠に何を入れたか
```

`Inventory` はクライアント側の持ち物の器で、同じ `HeldId` の表を読む。
サーバーは `Player.held` を受け取って、撃てない物を持っている間の射撃を弾く。

## 語彙

コードに出てくる名前と、その意味。**ここに無い言い方をコードで使わない。**

| 名前 | 意味 |
|---|---|
| **Player** | 人。体力・状態・位置・持ち物・成績。接続ではない (下記) |
| **Session** | 接続。`server/index.ts` に居る。socket・届く間隔・誰に何を配ったか |
| **Match** | 試合 = 部屋 1 つ。席・残機・段階 |
| **席 (seat)** | 部屋の中の 1 人分の枠。切れても 30 秒は空けて待つ |
| **残機 (ticket)** | 陣営の持ち点。死因を問わず 1 減り、0 にされた側が負け |
| **Life** | 席に着いてからの状態。`joining` `choosing` `spawning` `alive` `downed` `dropped`。**遷移できる組は表で決まっている** ([lifecycle.ts](lifecycle.ts)) |
| **Locomotion** | 体の動き (`idle` `sneak` `crouch_idle` `stab` `roll` `away` …) |
| **HeldId** | いま手にある物。**1 つだけ** (`rifle` `grenade` `knife` `box` `none` …) |
| **Family** | 持ち物の系統。`weapon` (Q で送る) と `tool` (C で送る) |
| **敵対** | 誰を撃てるか。ルールが決める (DM は全員、TDM は陣営) |
| **リンク** | 誰に情報が流れるか。**敬礼して作る**。まだコードに無い |
| **発光** | 位置が公になっている状態。リンクした味方 / 抜かれた相手 / DM の 1 位 |

### 人 (Player) と接続 (Session) は別

同じ人が繋ぎ直せば **Session は新しくなるが、Player は席に残る**。
30 秒だけ席を空けて待つ規則がここに出ている。

```
Player   (ここ)         体力 状態 位置 持ち物 成績
Session  (server 側)    socket 届く間隔 時計のずれ
                        誰に何を配ったか 遡って照合するための姿勢
```

分ける前は 1 つの構造体に 48 個のフィールドが並んでいて、**どれが遊びの話で
どれが回線の話なのか型から読めなかった**。

## 依存の向き

```
    ui ─▶ game ─▶ sim ─┐
                       ├─▶ domain
    server ─▶ net ─────┘
```

(game と server は domain も直に見る。矢印はどれも同じ向き、というのが要点)

**domain からは誰も見ない。** 見た瞬間に、規則が幾何や回線の都合を知ることになる。
弾の飛び方を変えるたびに「何発で死ぬか」が動く、が起きる。

陣営 (`Team`) の定義を `net` からここへ移したのもこれ。**protocol はゲームの
言葉を借りて話す側**であって、逆ではない。

規則は [layout.test.ts](layout.test.ts) が留めている (文書だけだと、半年後に
import を 1 本足した所で誰も気づかない)。

## まだ言葉になっていないもの

設計では決まっているのに、ここにまだ entity が無いもの。**遊びの背骨がここに
入るので、次に増えるのはこの辺り。**

- **Link** — 敬礼で作る網。敵対とは別のグラフ (design.md の 3)
- **Scanning / Plug** — 網を抜く動詞と、それを持てるスキル
- **発光 (leak)** — 抜かれた側に付く札。持続と、死んだら止まること
- **Skill** — 4 コストの予算。動詞を塞ぐ
- **Round / Time** — 湧き・ラウンド・試合の時間 (design.md の 6 は未着手)
