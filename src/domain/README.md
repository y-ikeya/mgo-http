# このゲームのドメイン

MGO2 という遊びそのものを、three も通信も知らない言葉で書いた層。

**ここが数字の出どころ。** 下の表を変えてから、コードを合わせる。表と実装が
ずれたら [spec.test.ts](spec.test.ts) が落ちる。

なぜその数字なのかは [docs/design.md](../../docs/design.md) と
[docs/weapons.md](../../docs/weapons.md)。

## 体

体力は **100** とする。撃たれずに屈んで待てば 35 まで回復する。

**銃弾は至近距離で頭に当たれば 1 発で死ぬ。** エイムが脅威として強いままだからこそ、それを
迂回する手に価値が出る。

部位ごとの基準ダメージは以下とする。距離で減衰する。

## 銃

1 回の装弾数と予備弾は以下とする。

<!-- 検査:銃 -->
| 武器 | 名前 | 装弾数 | 予備 | 重さ(kg) | リロード(秒) |
|---|---|---:|---:|---:|---:|
| smg | P90 | 50 | 100 | 2.6 | 3.0 |
| rifle | AK47 | 30 | 90 | 3.5 | 2.5 |
| sniper | XM2010 | 5 | 15 | 5.5 | 3.2 |
| pistol | M9 | 12 | 48 | 0.95 | 2.1 |
<!-- /検査 -->

**重さは移動の速さに効く。** 3.5kg を等倍として、1kg 軽いごとに 6% 速い。

    速さ = 1 + (3.5 − 重さ) × 0.06

    P90 105%   AK47 100%   XM2010 88%   M9 115%   手榴弾 119%

軽い物に持ち替えて走る、を戦法として成立させるためにこの形にしてある。

### 棲み分け

**同じ距離で 2 挺が競合しないようにする。** 主武器の 3 挺は「頭 1 発で殺せる
間合い」の広さと、その代わりに何を差し出すかで分かれる。

| | 受け持つ距離 | 強み | 代償 |
|---|---|---|---|
| **SMG** (P90) | 〜12m | 装弾 50 発、900 発/分、反動が小さい。軽くて小回りが利く | **頭 1 発の間合いが狭い** (30m から先は頭 4 発)。リロードが 3 秒と長い |
| **AR** (AK47) | 15〜40m | 頭 1 発が 25m まで届いて連射もできる万能 | 遠距離は頭 1 発にならず、狙いにくい |
| **SNIPER** (XM2010) | 全距離 | **どこから撃っても頭 1 発。**スコープがある | 連射できない (1.57 秒に 1 発)、重い (速さ 88%)、弾倉 5 発 |

頭 1 発で殺せる距離と、そこから先の落ち方:

<!-- 検査:射程 -->
| 武器 | 等倍まで(m) | 頭打ち(m) | 下限 |
|---|---:|---:|---:|
| smg | 12 | 30 | 0.25 |
| rifle | 25 | 60 | 0.3 |
| sniper | 200 | 200 | 1 |
| pistol | 10 | 22 | 0.25 |
<!-- /検査 -->

    距離        SMG        AR
    12m まで    頭 1 発    頭 1 発
    20m         頭 2 発    頭 1 発      ← ここが AR の間合い
    30m 以降    頭 4 発    頭 1〜2 発
    60m 以降    頭 4 発    頭 4 発      どちらも狙撃銃に負ける

連射は SMG が 900 発/分 (0.065 秒間隔)、AR が 660 発/分 (0.09 秒)。
**胴で削り合えばほぼ互角**にしてある — SMG は 1 発 15 で 7 発 (0.39 秒)、
AR は 20 で 5 発 (0.36 秒)。**近くでは AR がわずかに速い。** SMG が勝つのは
弾倉の大きさと足の速さであって、殴り合いの強さではない。

> **SG (ショットガン) はまだ無い。** 短距離で、当たった相手を怯ませるので突撃に
> 向く。**頭 1 発では死なない**枠として入れる (design.md の 5)。

## 投げる物・置く物

1 つの命で持てる数は以下とする。倒れて湧くたびに戻る。

<!-- 検査:支援 -->
| id | 名前 | 数 |
|---|---|---:|
| grenade | GRENADE | 3 |
| claymore | CLAYMORE | 2 |
<!-- /検査 -->

弾倉 (`magazine`) は枠で選ばない。撃った弾が 1 弾倉ぶん溜まるごとに増える。

手榴弾は爆心 **75** / 届く **7m**、クレイモアは至近 **75** / 端 **25**、正面
**4m** で反応して **6m** まで届く。**どちらも単体では死なない** (体力 100)。

## 手に持てる物

**手にあるのは常に 1 つだけ。** 手榴弾も例外ではない — 銃を持ったまま投げるの
ではなく、持ち替える。

系統は 2 つ。**武器 (Q で送る)** と **道具 (C で送る)**。系統をまたぐ送りは
しない。道具の一覧には `none` (何も使わない) が並んでいて、そこへ送ると手に
武器が戻る。

## 近接

間合いは **2m**。背後から **100** (即死)、正面から **50**。

倒れている相手は、**ナイフを構えて見下ろせば**刺さる (`-0.35 rad` 以下)。
真っ直ぐ前を刺しても届かない。

> 背後も正面も 100 (どこを刺しても即死) にすると決めてある。ただし
> **持ち替えのモーションと同時に入れる** — 銃を一瞬でしまって刺せるうちに
> 即死にすると、代償が無いまま報酬だけが残る。

## 試合

<!-- 検査:試合 -->
| | 値 |
|---|---:|
| 残機 (ticket) | 20 |
| 試合の長さ (秒) | 300 |
| 始めるのに要る人数 | 2 |
| 席を空けて待つ (秒) | 30 |
<!-- /検査 -->

**残機は死因を問わず 1 減る。** 撃たれても自爆しても自陣の損は同じで、倒した
側には何も入らない。「殺されるくらいなら自死する」を成り立たなくするため。

0 にされた側が負け。時間切れなら多く残っているほうが勝ち。残機はサーバーの
環境変数で上書きできる (`MGO2_TICKETS`) — **実際に回して詰める**数なので、
箱の上で試すのに再配置が要らないようにしてある。

| | 秒 |

| 湧いた直後の無敵 | 3 |

**早く選んだぶん早く戻れる、にはしない** (OK が効くまで 3 秒)。選ぶのが速い
ことは腕前ではない。

## 状態 (Life)

席に着いてからの状態。**遷移できる組は表で決まっている**
([lifecycle.ts](lifecycle.ts))。

| | |
|---|---|
| `joining` | 席はあるが、まだ位置を知らせていない。誰にも配らない |
| `choosing` | 装備を組んでいる。戦場に居ない |
| `spawning` | 湧いた直後。戦場に居るが、まだ撃たれない。撃てば自分から解く |
| `alive` | 戦場に居て、撃たれる |
| `downed` | 倒れている。自分で起きる |
| `dropped` | 切れた。席は 30 秒だけ空けて待つ |

## 情報 (決めてあるが、まだコードに無い)

**ここが遊びの背骨。** 敵対とリンクは別のグラフとする。

| | 何を決めるか | どう決まるか |
|---|---|---|
| 敵対 | 誰を撃てるか | ルール (DM は全員、TDM は陣営) |
| リンク | **誰に情報が流れるか** | **プレイヤーが敬礼して作る** |

- 味方でも自動では見えない。**敬礼してリンクして初めて**情報が流れる
- リンクは**網**。A-B と B-C が繋がっていれば A も C を知る
- リンク中の相手を CQC で捕まえて scanning すると、**その網の全員**が漏れる
- 漏れた側は**体が光る**。死ねば止まる
- scanning には skill が要る (無ければ Plug を持てない)。誰でもできはしない

## 語彙

コードに出てくる名前と意味。**ここに無い言い方をコードで使わない。**

| 名前 | 意味 |
|---|---|
| **Player** | 人。体力・状態・位置・持ち物・成績 |
| **Session** | 接続。`server/index.ts` に居る。socket・届く間隔・誰に何を配ったか |
| **Match** | 試合 = 部屋 1 つ。ルール (Mode) を持つ |
| **Mode** | 部屋のルール (`DM` `TDM` `TSNE` `INT` `PRACTICE`)。誰が敵かはこれが決める |
| **的 (bot)** | 接続を持たない Player。練習部屋に並ぶ棒立ち |
| **席 (seat)** | 部屋の中の 1 人分の枠。切れても 30 秒は空けて待つ |
| **残機 (ticket)** | 陣営の持ち点 |
| **Life** | 上の 6 状態 |
| **Locomotion** | 体の動き (`idle` `sneak` `crouch_idle` `stab` `roll` `away` …) |
| **HeldId** | いま手にある物。1 つだけ |
| **Family** | 持ち物の系統 (`weapon` / `tool`) |
| **発光** | 位置が公になっている状態。リンクした味方 / 抜かれた相手 / DM の 1 位 |

### 人 (Player) と接続 (Session) は別

同じ人が繋ぎ直せば **Session は新しくなるが、Player は席に残る**。
席を 30 秒空けて待つ規則がここに出ている。

```
Player   (ここ)         体力 状態 位置 持ち物 成績
Session  (server 側)    socket 届く間隔 時計のずれ
                        誰に何を配ったか 遡って照合するための姿勢
```

## 依存の向き

```
    ui ─▶ game ─▶ sim ─┐
                       ├─▶ domain
    server ─▶ net ─────┘
```

**domain からは誰も見ない。** 見た瞬間に、規則が幾何や回線の都合を知ることに
なる。陣営 (`Team`) の定義を `net` からここへ移したのもこれ。
[layout.test.ts](layout.test.ts) が留めている。

## まだ言葉になっていないもの

設計では決まっているのに、entity が無いもの。

- **Link** — 敬礼で作る網
- **Scanning / Plug** — 網を抜く動詞と、それを持てるスキル
- **発光 (leak)** — 抜かれた側に付く札。持続と、死んだら止まること
- **Skill** — 4 コストの予算。動詞を塞ぐ
- **Round / Time** — 湧き・ラウンド・試合の時間 (design.md の 6 は未着手)
